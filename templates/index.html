📋 ক্লোন করুন 🌐 GitHub-এ দেখুন

⚡ Termux-এ রান করার ধাপ

# ১. স্টোরেজ পারমিশন termux-setup-storage # ২. রিপো ক্লোন করুন git clone https://github.com/obbany/Youtube-Downloader.git # ৩. ফোল্ডারে যান cd Youtube-Downloader # ৪. ডিপেন্ডেন্সি ইনস্টল pip install -r requirements.txt # ৫. সার্ভার চালু করুন python app.py

📱 ব্যবহার করার নিয়ম

  1. Termux ওপেন করুন এবং উপরের কমান্ডগুলো দিন।
  2. সার্ভার চালু হলে IP ঠিকানা দেখাবে (যেমন: http://192.168.x.x:5000)।
  3. একই Wi-Fi নেটওয়ার্কে থাকা যেকোনো ডিভাইসের ব্রাউজারে এই লিংকটি দিন।
  4. YouTube লিংক পেস্ট করুন → কোয়ালিটি সিলেক্ট করুন → ডাউনলোড করুন!
